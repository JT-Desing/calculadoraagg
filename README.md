# Calculadora de tarifas ePayco

Calculadora estatica para simular tarifas, retenciones y abono estimado con comparativo entre Davivienda/DaviPlata y otros bancos.

## Archivos

- `index.html`: estructura de la interfaz.
- `styles.css`: estilos responsive y visuales.
- `app.js`: calculos, autocompletado de ciudad y comportamiento interactivo.

## Publicacion

El sitio esta preparado para publicarse directamente con GitHub Pages desde la rama `main`.
